# SVAR File Manager

The file browser adapts the Willow theme spacing, selection colors, borders,
and table/toolbar layout from @svar-ui/svelte-filemanager 2.6.0.
Source: https://github.com/svar-widgets/filemanager
Revision: b7c76cb0970a9129dd284cf3aa881b80820f811c
Reference files: svelte/src/themes/Willow.svelte and
svelte/src/components/{Toolbar,Breadcrumbs,Table/View}.svelte.

No Svelte runtime, SVAR dependencies, icon fonts, or CDN images are included.
The inline outline SVG icons are original drawings for this plugin.
The dialog implementation uses the browser dialog element and the existing
plugin protocol. Theme colors are adapted to MeshCentral, including body.night.
